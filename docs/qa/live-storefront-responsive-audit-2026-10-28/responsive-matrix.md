## 2. In-Depth Responsive Layout Observations

1. **Horizontal Containment (0% Overflow across all 13 viewports):**
   - At no viewport width did the document scrollWidth exceed window.innerWidth.
   - Tested down to the narrowest supported breakpoint ($320\text{px}$ small mobile); text wraps cleanly within cards, buttons wrap without clipping, and horizontal carousels (e.g. Audience cards, Category sliders) use native momentum touch scrolling without forcing parent container overflow.
2. **Sticky Header Transition:**
   - On desktop ($\ge 1024\text{px}$), the header starts at height $68\text{px}$ and cleanly shifts to compact state upon scrolling past $50\text{px}$ without layout jitter.
   - On tablet ($600\text{px} - 1023\text{px}$), the two-tier header operates at $106\text{px}$ preserving search access.
   - On mobile ($< 600\text{px}$), the sticky bar occupies a compact $58\text{px}$ height with search icon and mobile drawer hamburger.
3. **Card Grid Reconfiguration:**
   - **Homepage Products:** Adapts seamlessly from 2-column on mobile ($320\text{px} - 600\text{px}$), to 3-column on tablet ($768\text{px}$), to 4-column on desktop ($1024\text{px} - 1440\text{px}$), to 5-column on wide desktop ($1920\text{px}$).
   - **Catalog Search Grid:** 2-column on mobile, 3-column on desktop with sticky filter rail.
   - **Wishlist Grid:** 4-column layout preserved on standard and large desktop.
4. **Footer Mobile Stacking:**
   - Desktop displays 4 balanced columns (Shop, Categories, Brands, Sourcing) alongside company details.
   - At $\le 768\text{px}$, footer columns stack vertically with generous touch targets ($44\text{px}+$ tap area) and balanced vertical rhythm.
